# Hardy — brand book

*Buy it once.*

Source of truth for colour, type, marks and voice. Tokens live in `brand/tokens.css`.
Two runnable checks enforce this document: `brand/cvd.py` and `brand/contrast.py`.
If you change a colour, run them. They are not decoration — both have caught real failures.

---

## 0. The constraint that shapes everything

**Hardy's designer is colour blind.** So no part of this system may depend on hue alone.

Every colour decision here is verified by `brand/cvd.py`, which simulates protanopia,
deuteranopia and tritanopia using the Viénot–Brettel–Mollon LMS transform and then checks that
(a) every text pair still clears WCAG AA and (b) every semantic colour stays measurably distinct
from every other one, *under each dichromacy*.

```
$ python3 brand/cvd.py
ALL CHECKS PASS — palette is legible with normal vision and all three dichromacies.
```

Wherever colour carries meaning it is paired with a second channel: a text label, a shape, or a
luminance step. Colour is always the redundant signal, never the only one.

## 1. Where this design came from

Not invented. Extracted from the two brands that own "hard-wearing tool" in the public mind,
by pulling their live computed styles with Playwright.

**Milwaukee Tool** — `milwaukeetool.com`

```
backgrounds  #0A0A0A · #424242 · #FFFFFF
accent       #DB011C   (one, and only one)
display      Helvetica Neue LT W01_83 Hv Ex   <- Heavy EXTENDED
weights      400 body / 700 display, nothing between
```

**DeWalt** — `dewalt.com`

```
backgrounds  #000000 · #231E20 · #FFFFFF
accent       #FEBD17   (one, and only one)
display      archivoExpanded                  <- Archivo EXPANDED
weights      400 body / 800–900 display
```

Two independent hardware giants, the same four rules:

1. **Near-black base.** Not cream, not grey-100. The page is the void.
2. **Exactly one high-chroma accent.** Never two competing brights.
3. **Expanded heavy grotesque for display.** Width is the industrial signal, not just weight.
4. **Extreme weight contrast.** 400 or 800+. The middle weights are what make a page look timid.

Hardy follows all four. The first version of this brand book used a soft warm cream palette with
a muted brass accent and normal-width type — the default tasteful-startup look. That is precisely
why it read as generic. The correction is above, and it is sourced.

## 2. Marks

| Mark | File | Use |
|---|---|---|
| Wordmark | `logo/hardy-wordmark.png` | Header, README, video title card, social |
| Monogram | `logo/hardy-monogram.png` | Favicon, app icon, avatar, tight spaces |

Machined stainless steel, brushed and genuinely scratched, with a **hot amber rim-light** raking
every bevel — rendered on pure black. Generated by `logo/gen.py` (`gemini-3-pro-image`).

**They are rendered on black on purpose.** The first pass rendered them on a white studio sweep
and then tried to key the background out. That failed repeatedly for a real reason: blown specular
highlights on polished steel are *the same colour as a white backdrop*, so no threshold can
separate them without eating the metal. Rendering on the brand's own background removes the
problem instead of fighting it — and the amber rim, which exists to separate metal from darkness,
only makes sense in a dark context anyway. The mark and the brand are lit by the same logic.

**Rules**
- Clear space on all sides ≥ the height of the `H`.
- Never recolour, never re-light, never place on a light background.
- Minimum wordmark width `8rem`. Below that, use the monogram.
- The amber in the rim is the same amber as `--amber`. It is where the accent comes from.

## 3. Colour

### 3.1 Base — the void and the steel ramp

| Token | Hex | Role |
|---|---|---|
| `--void` | `#0B0B0C` | Page. Near-black, faintly cool. |
| `--steel-900` | `#16171A` | Raised surface, cards |
| `--steel-800` | `#1F2125` | Sunken wells, table stripes |
| `--steel-700` | `#2C2F35` | Borders, hairlines |
| `--steel-500` | `#6E747E` | Disabled |
| `--steel-400` | `#8B929C` | Muted metadata |
| `--steel-300` | `#A8AEB8` | Secondary text |
| `--steel-100` | `#E6E9ED` | Body text |
| `--white` | `#FFFFFF` | Headings |

### 3.2 The one accent

| Token | Hex | Role |
|---|---|---|
| `--amber` | `#FFB302` | **The accent.** Links, focus, primary action, cost-per-year. |
| `--amber-hot` | `#FFC93D` | Hover |
| `--amber-deep` | `#C98A00` | Pressed, borders on amber fills |
| `--signal` | `#4DA3FF` | The *only* second hue. Data/debug channel. |

Amber is not a taste choice. It is the one high-chroma hue that is simultaneously
(a) authentic to the category, (b) already present in the mark's rim-light, and
(c) **the safest possible accent for a colour-blind viewer** — yellow-orange survives
protanopia and deuteranopia, which red does not. Milwaukee's red would have failed this brand.

Amber and `--signal` blue are maximally separable under every dichromacy — verified at
d=422 (deuteranopia), d=404 (tritanopia). Orange-vs-blue is the strongest CVD-safe pairing there is.

### 3.3 Ownership badges — colour is the *redundant* channel

`HARDY.md` §3.4 records the top-voted correction in our own source thread:

> *"This sub does not know the difference between private equity and larger conglomerates…
> They are hugely different business models."*

**So there is no red and no green in the ownership system.** Not one hue meaning bad, not one
meaning good. A confidence scale, not a moral one — and it is carried by **border, fill, shape
and text together**, so it survives being seen in greyscale.

| Ownership | Border | Fill | Shape marker | Text |
|---|---|---|---|---|
| `trust` · `family` · `employee` | solid `--amber` | `--amber-ghost` | ◆ filled diamond | `--amber` |
| `public` · `conglomerate` | solid `--steel-700` | none | ■ filled square | `--steel-300` |
| `private_equity` | solid `--steel-700` | none | ■ filled square **+ the year** | `--steel-300` |
| `unknown` | **dashed** `--steel-700` | none | ○ hollow circle | `--steel-500` |

`private_equity` and `conglomerate` get **identical colour treatment**. The only difference is
that PE carries its acquisition date. The date persuades, because the date is a fact.
`unknown` is deliberately styled as unfinished — honesty should be visible.

### 3.4 Process-map lanes

Seven lanes, chosen by search rather than taste: `brand/cvd.py` optimised over a candidate pool
to **maximise the minimum pairwise separation across all three dichromacies simultaneously**.

| Lane | Hex | |
|---|---|---|
| Browser | `#56B4E9` | sky |
| Ingest | `#F0E442` | yellow |
| Trigger | `#CC79A7` | purple |
| Agent | `#6BE1A0` | mint |
| Retrieval | `#7F5FFF` | violet |
| Store | `#D55E00` | vermillion |
| Mesh | `#FFB302` | **brand amber** |

Worst-case separation **d = 102.6** (tritanopia, trigger vs store). Every lane also carries a
text prefix in the node label — `BROWSER ·`, `AGENT ·` — so the map is fully readable in greyscale.

Two findings worth keeping: the standard Okabe-Ito "reddish purple" `#CC79A7` collapses into
neutral grey under protanopia, so it can never sit beside a grey lane. And `#E69F00` is
indistinguishable from `#FFB302` for everyone — two ambers is one amber.

### 3.5 Reserved

`--state-error #FF6B5A` and `--state-ok #6BE1A0` are for **system state only**: form errors, the
`/debug` in-sync boolean. Never for a brand, a product, or an ownership type.

## 4. Type

| Role | Family | Why |
|---|---|---|
| Display | **Archivo Expanded** 800/900 | The face DeWalt actually ships. Width is the industrial signal. Uppercase, tight tracking. |
| UI + body | **Archivo** 400/500 | Same superfamily, so chrome and headline share a voice. |
| Numeric | **IBM Plex Mono** 400 | Tabular figures for price, cost-per-year, scores, `/debug`. |

Vendored at `brand/fonts/ArchivoExpanded-*.ttf` — self-hosted, no CDN, no build step.
Archivo's width axis is not reachable through Figma's plugin API, so the **static Expanded
instances are installed rather than substituting a lookalike.**

Scale: modular, ratio **1.25**, base **1rem = 16px**, `rem` everywhere.
`--text-2xs` 0.694 · `xs` 0.8 · `sm` 0.875 · `base` 1 · `lg` 1.25 · `xl` 1.563 ·
`2xl` 1.953 · `3xl` 2.441 · `4xl` 3.052 · `5xl` 3.815 · `6xl` 4.768

Headings are `uppercase`, `letter-spacing: -0.03em`, `line-height: 0.92` at hero size.
Body is 1.6 with a 66ch measure. Never set body below `--text-base`.

### The cost-per-year rule

Price comparison is the **#1 trust signal at 48%** (King's audit F5). Cost-per-year is Hardy's
differentiated number, so it gets **identical size, weight and position to the price** — never
small grey text underneath.

```
₹1,42,000                    ₹7,100 / YEAR
--text-xl / white            --text-xl / --amber
```

The accent colour does the arguing. And because amber-vs-white is a luminance difference as much
as a hue difference, the emphasis still reads under every dichromacy.

## 5. Voice

Plain, unhurried, specific. A knowledgeable friend in a hardware shop. Gives you the number and
the reason, then points at one thing.

**Never:** exclamation marks · hype · urgency or scarcity · moralising about consumption ·
asserting that a brand declined. Hardy quotes cited evidence or says nothing.

| Instead of | Write |
|---|---|
| "Great news! Amazing deals on durable cookware!" | "You've opened three skillets this week." |
| "This product is built to last!" | "₹2,100 a year across a 20-year service life." |
| "Bosch has gone downhill since the buyout." | *"Owners report the small appliances have slipped."* — r/BuyItForLife |
| "Don't waste money on cheap tools." | "Buy the Miele if you'll stay a decade. Buy the Bosch if you won't." |

Buttons are verbs in sentence case. Labels are uppercase mono with `0.16em` tracking.

## 6. Layout & accessibility floor

- **Spacing** `0.25rem` base: 1 / 2 / 3 / 4 / 6 / 8 / 12 / 16 / 24 / 32. Nothing off-scale.
- **Radius** `0.125rem` and `0.25rem` only. Hardware is not rounded.
- **Depth comes from the steel photography, not from chrome.** Borders over shadows.
- **Breakpoints** 40 / 48 / 64 / 80rem. Every component works 360px → 1920px, mobile-first.
- Body ≥ 4.5:1, large ≥ 3:1 — verified under normal vision *and* all three dichromacies.
- Focus ring `2px solid var(--amber)`, `2px` offset, on every interactive element. Never `outline: none`.
- Hit targets ≥ `2.75rem`.
- `prefers-reduced-motion` respected on every transition.
