# Hardy — brand book

*Buy it once.*

Source of truth for colour, type, marks, spacing and voice. Tokens live in `brand/tokens.css`.
Figma: **Hardy — Brand Book**, six pages — Cover, Foundations, Colour, Type, Components, Voice.

---

## 1. Where this came from

Nothing here was invented from taste. The design language was extracted from the two brands that
own hard-wearing tools in the public mind, by pulling their **live computed styles** off their
production sites with Playwright.

**Milwaukee Tool** — `milwaukeetool.com`

```
base     #0A0A0A · #424242 · #FFFFFF
accent   #DB011C   (one, and only one)
display  Helvetica Neue LT W01_83 Hv Ex   <- Heavy EXTENDED
weights  400 body / 700 display, nothing between
```

**DeWalt** — `dewalt.com`

```
base     #000000 · #231E20 · #FFFFFF
accent   #FEBD17   (one, and only one)
display  archivoExpanded                  <- EXPANDED
weights  400 body / 800–900 display
```

Two independent hardware giants, the same four rules:

1. **Near-black base.** Not cream, not grey-100. The page is the void.
2. **Exactly one high-chroma accent.** Never two competing brights.
3. **Expanded heavy grotesque for display.** Width is the industrial signal, not just weight.
4. **Extreme weight contrast.** 400 or 800+. The middle weights make a page look timid.

Hardy follows all four. The first version of this brand book used warm cream with a muted brass
accent and normal-width type — the default tasteful-startup look. That is exactly why it read
as generic, and why the rule above exists.

## 2. Marks

| Mark | File | Use |
|---|---|---|
| Wordmark | `logo/hardy-wordmark.png` | Header, README, video title card, social |
| Monogram | `logo/hardy-monogram.png` | Favicon, app icon, avatar, tight spaces |

Machined stainless steel, brushed and genuinely scratched, with a restrained brass edge on every
bevel. Generated by `logo/gen.py` (`gemini-3-pro-image`), keyed to transparency by `logo/alpha.py`.

**Rendered on black on purpose.** The first pass rendered on a white studio sweep and tried to
key the background out. That failed repeatedly for a real reason: blown specular highlights on
polished steel are *the same colour as a white backdrop*, so no threshold separates them without
eating the metal. Rendering on the brand's own background removes the problem instead of fighting it.

**Rules**
- Clear space on all sides ≥ the height of the `H`.
- Never recolour, never re-light, never place on a light surface — the shadowed extrusion faces
  are near-black and read as damage on white.
- Minimum wordmark width `8rem`. Below that, use the monogram.
- The brass in the bevel is where `--amber` comes from. They are the same family.

## 3. Colour

### 3.1 Warm charcoal, not cool black

The mark is warm steel with a brass bevel. So the surfaces are warm too — they sit in the same
temperature family instead of fighting it. It reads as oiled metal rather than screen chrome.

| Token | Hex | Role |
|---|---|---|
| `--void` | `#100E0C` | Page |
| `--steel-900` | `#1B1815` | Raised surface, cards |
| `--steel-800` | `#241F1B` | Sunken wells, table headers |
| `--steel-700` | `#332E28` | Borders, hairlines |
| `--steel-600` | `#47403A` | Dividers |
| `--steel-500` | `#6E655C` | Disabled |
| `--steel-400` | `#8E8478` | Muted metadata |
| `--steel-300` | `#ADA396` | Secondary text |
| `--steel-200` | `#CBC3B8` | Bright metadata |
| `--steel-100` | `#E9E4DC` | Body text |
| `--white` | `#FFFFFF` | Headings |

### 3.2 The one accent

| Token | Hex | Role |
|---|---|---|
| `--amber` | `#FFB302` | **The accent.** Links, focus, primary action, cost-per-year. |
| `--amber-hot` | `#FFC93D` | Hover |
| `--amber-deep` | `#C98A00` | Pressed, borders on amber fills |
| `--signal` | `#4DA3FF` | The only second hue. Data/debug channel. |

Amber is authentic to the category, already present in the mark's bevel, and clears **10.7:1**
on the page. One accent, never two.

### 3.3 Ownership badges

`HARDY.md` §3.4 records the top-voted correction in our own source thread:

> *"This sub does not know the difference between private equity and larger conglomerates…
> They are hugely different business models."*

**So there is no red and no green in the ownership system.** Not one hue meaning bad, not one
meaning good. It is a confidence scale, carried by **border, fill, shape and text together**.

| Ownership | Border | Fill | Shape | Text |
|---|---|---|---|---|
| `trust` · `family` · `employee` | solid `--amber` | `--amber-ghost` | ◆ diamond | `--amber` |
| `public` · `conglomerate` | solid `--steel-700` | none | ■ square | `--steel-300` |
| `private_equity` | solid `--steel-700` | none | ■ square **+ the year** | `--steel-300` |
| `unknown` | **dashed** | none | ○ hollow circle | `--steel-500` |

`private_equity` and `conglomerate` render **identically**. The only difference is that PE
carries its acquisition date — the date is a fact, the verdict would be an opinion.
`unknown` is deliberately styled as unfinished, because honesty should be visible.

### 3.4 Accessibility

Standard production hygiene, not an optional pass. Roughly 1 in 12 men has some colour vision
deficiency, so this is a real slice of the market, not an edge case.

- Every text pairing clears **WCAG AA** (4.5:1 body, 3:1 large).
- **Meaning is never carried by hue alone** — always hue plus a label, a shape, or a luminance step.
  That is why the ownership badges have four distinct shape markers and the process-map lanes
  carry text prefixes.
- `brand/cvd.py` verifies both, and also checks the palette holds under the three dichromacies.
  Run it before committing any colour change. It has already caught three failing tokens and two
  colliding lane colours.

Process-map lanes: `#56B4E9` browser · `#F0E442` ingest · `#CC79A7` trigger · `#6BE1A0` agent ·
`#7F5FFF` retrieval · `#D55E00` store · `#FFB302` mesh.

## 4. Type

| Role | Family | Why |
|---|---|---|
| Display | **Encode Sans Expanded** Black / ExtraBold | Genuinely expanded, squared terminals, engineered rather than styled. Width is the industrial signal. |
| UI + body | **Archivo** 400 / 500 | Neutral workhorse. Nav, buttons, labels, body. |
| Numeric | **IBM Plex Mono** 400 | Tabular figures. Price, cost-per-year, scores, `/debug`. |

Scale: modular, ratio **1.25**, base **1rem = 16px**.
`--text-2xs` 0.694 · `xs` 0.8 · `sm` 0.875 · `base` 1 · `lg` 1.25 · `xl` 1.563 ·
`2xl` 1.953 · `3xl` 2.441 · `4xl` 3.052 · `5xl` 3.815 · `6xl` 4.768

Type sizes stay in **rem** so they never compound down a nested tree.
Headings are uppercase, `letter-spacing: -0.025em`, `line-height: 0.94` at hero size.
Body is 1.6 with a 66ch measure. Never set body below `--text-base`.

### The cost-per-year rule

Price comparison is the **#1 trust signal at 48%** (King's audit F5). Cost-per-year is Hardy's
differentiated number, so it gets **identical size, weight and position to the price** — never
small grey text underneath.

```
₹1,42,000                    ₹7,100 / YEAR
--text-xl / --white          --text-xl / --amber
```

The accent does the arguing. Because amber differs from white in luminance as well as hue, the
emphasis holds even where colour is lost.

## 5. Spacing

**One value. `1em`. All four sides, every gap.**

```css
padding: var(--pad);   /* 1em — top, right, bottom, left, equal */
gap: var(--gap);       /* 1em */
```

- Never a per-side value. Never a raw number. Never `px`.
- `--space-2` / `--space-3` / `--space-4` (2em/3em/4em) exist **only** to separate major page
  sections. Inside a component it is always `1em`.
- `em` is relative to the element's own `font-size`, so a badge at `--text-xs` gets
  proportionally tighter padding for free while still being written as `1em`. One number,
  correct at every scale.

Radius `0.125rem` / `0.25rem` only — hardware is not rounded. Depth comes from the steel
photography, not from chrome: borders over shadows. Breakpoints 40 / 48 / 64 / 80rem.
Every component works 360px → 1920px, mobile-first.

## 6. Voice

Plain, unhurried, specific. A knowledgeable friend in a hardware shop. Gives you the number and
the reason, then points at one thing.

**Never:** exclamation marks · hype · urgency or scarcity · moralising about consumption ·
asserting that a brand declined. Hardy quotes cited evidence or says nothing.

| Instead of | Write |
|---|---|
| "Great news! Amazing deals on durable cookware!" | "You've opened three skillets this week." |
| "This product is built to last!" | "₹2,100 a year across a 20-year service life." |
| "Bosch has gone downhill since the buyout." | *"Owners report the small appliances have slipped."* — r/BuyItForLife |
| "Don't waste money on cheap tools." | "Buy the Miele if you'll stay a decade. Buy the Bosch if you won't." |

Buttons are verbs in sentence case. Labels are uppercase mono with `0.16em` tracking.
Focus ring `2px solid var(--amber)`, `2px` offset, on every interactive element. Hit targets ≥ `2.75rem`.
